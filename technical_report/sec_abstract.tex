\begin{abstract}
\noindent
We describe our solution to the \texttt{fused\_moe} track of the FlashInfer AI Kernel Generation Contest at MLSys 2026, targeting NVIDIA B200 (Blackwell, SM100) GPUs.
The task is to implement the fastest correct kernel for a Mixture-of-Experts feed-forward layer drawn from DeepSeek-V3/R1~\cite{deepseek}, with FP8 block-scale quantized weights and a hierarchical Top-K routing scheme.
\textbf{The kernel was developed end-to-end with AI assistance} (agent-assisted code generation, profiling, and iterative optimization).
Our final Triton~\cite{triton} implementation achieves a peak speedup of \textbf{7.43$\times$} (sequence length $T{=}1$) and passes all \textbf{19/19} benchmark workloads, with 2.3--2.4$\times$ on long-context inputs ($T{>}10{,}000$).
Key contributions are: (1)~lossless FP8$\to$BF16 promotion enabling BF16 tensor cores at zero precision cost; (2)~a fused GEMM1+SwiGLU Triton kernel sharing the A-tile across gate and up projections; (3)~a 4-operation dispatch table replacing 96 sequential GPU kernel launches; (4)~route-weight fusion into the GEMM2 store epilogue eliminating one full output re-read per expert; and (5)~FP8 bulk gather reducing token-data bandwidth by $4\times$.
\end{abstract}
